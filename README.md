# Your Spotify Festival
Maak je eigen Festival poster met een lineup van je meest beluisterde artiesten op Spotify!

- https://spotify-api-visual-production-08b4.up.railway.app

## Tech Stack
- NodeJS
- ExpressJS
- Express-Session
- EJS
- dotenv

## Installatie
1. Clone dit project naar je lokale machine
2. Open je terminal en vul in:
```
npm install
```
3. Maak een .env bestand aan en zorg dat deze velden gevuld zijn:
```
CLIENT_ID=<jouw-spotify-client-id>
CLIENT_SECRET=<jouw-spotify-client-secret>
```
4. Wanneer dit ingevuld is start je de applicatie met:
```
npm run start
```
5. Ga naar http://127.0.0.1:3000
